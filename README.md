# JUCE Synth

A learning project exploring synthesizer development with C++ and JUCE.

The eventual goal is to build a polyphonic synthesizer that can be packaged
as an AUv3 instrument and used in GarageBand / Logic Pro.

## Current Status

Phase 1.5 — Basic Synth Voice

- [x] Sine oscillator
- [x] Audio output
- [x] Amplitude envelope
- [x] SynthVoice abstraction
- [ ] MIDI input
- [ ] Polyphony
- [ ] Filter
